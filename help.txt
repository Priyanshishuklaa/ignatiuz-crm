===============================================================
  CRM PRO — PROJECT SETUP & RUN GUIDE
  Everything you need to get the app running from scratch
===============================================================

PREREQUISITES:
  - Node.js v18+ installed (check: node --version)
  - npm installed (comes with Node.js, check: npm --version)

===============================================================
1. INSTALL DEPENDENCIES
===============================================================

  # Backend (from project root):
  cd server
  npm install

  # Frontend (from project root):
  cd client
  npm install

===============================================================
2. START THE APPLICATION
===============================================================

  # Terminal 1 — Start Backend API Server (port 5000):
  cd server
  node index.js

  # Terminal 2 — Start Frontend Dev Server (port 5173):
  cd client
  npm run dev

  # Open in browser:
  http://localhost:5173

===============================================================
6. TECH STACK
===============================================================

  Backend:
    - Node.js + Express.js    (REST API server)
    - better-sqlite3           (Embedded SQL database)
    - bcryptjs                 (Password hashing)
    - jsonwebtoken             (JWT authentication)
    - nodemailer               (Transactional emails)

  Frontend:
    - React 19                 (UI framework)
    - Vite 8                   (Build tool + dev server)
    - React Router DOM 7       (Client-side routing)
    - Axios                    (HTTP client)
    - Lucide React             (Icons)
    - React Hot Toast          (Notifications)
    - Vanilla CSS              (Custom design system)

===============================================================
7. EMAIL PREVIEW (Demo)
===============================================================

  The app uses Ethereal (free test SMTP) for email demo.
  When the server starts, it prints Ethereal credentials:

    📧 Email service initialized (Ethereal Test SMTP)
       Preview inbox: https://ethereal.email/login
       Email: <auto-generated>
       Pass:  <auto-generated>

  To preview sent emails:
    1. Go to https://ethereal.email/login
    2. Enter the Email/Pass shown in the server terminal
    3. Check the inbox — you'll see welcome & login emails

===============================================================
8. USEFUL COMMANDS
===============================================================

  # Reset database (delete and restart server):
  del server\crm.db
  cd server && node index.js

  # Check which ports are in use:
  netstat -ano | findstr :5000
  netstat -ano | findstr :5173

  # Kill a process on a port (replace PID):
  taskkill /PID <PID> /F

  # Build frontend for production:
  cd client
  npm run build
